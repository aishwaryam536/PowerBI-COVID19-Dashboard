# COVID-19 Data Analysis Dashboard – Power BI

## Project Overview

This project presents an interactive COVID-19 data analysis dashboard developed using Microsoft Power BI.

The project analyzes COVID-19 confirmed cases, deaths, recovered cases, active cases, daily new cases, daily new deaths, testing, population, and geographic trends.

## Dashboard Views

### 1. Country-Wise Analysis

This dashboard provides country-level COVID-19 analysis.

Key analysis includes:

- Confirmed Rate
- Active Cases
- Confirmed Cases
- Total Deaths
- Total Recovered Cases
- Daily New Deaths
- Recovered Cases by Country
- Geographic distribution of COVID-19 data

## Data Preparation

The dataset was imported into Power BI and prepared for analysis using Power Query.

Data cleaning and transformation were performed to prepare the dataset for dashboard development.

## DAX

DAX was used to create calculated measures and KPIs required for the analysis, including measures related to confirmed cases, deaths, recovered cases, active cases, testing, and other COVID-19 metrics.
