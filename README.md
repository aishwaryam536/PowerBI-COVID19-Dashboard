# COVID-19 Analysis Dashboard — Power BI

## Project Overview
This project analyzes COVID-19 data using Power BI to explore confirmed cases, recoveries, deaths, and the spread of the pandemic across countries and regions.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (if used)

## Dashboard Analysis
- Confirmed COVID-19 cases
- Recovered cases
- Death counts
- Country-wise and region-wise analysis
- COVID-19 trends and comparisons

## Key Skills Demonstrated
- Data cleaning and transformation
- Data analysis
- Data visualization
- Interactive dashboard design
